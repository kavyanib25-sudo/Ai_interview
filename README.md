# AI Adaptive Interview Engine

An interactive AI-powered interview practice website that dynamically adjusts interview questions based on the candidate's performance.

## Features

- Topic and subtopic selection
- Adaptive question difficulty
- Correct, wrong, and skipped answer tracking
- Repeated answer detection
- Duplicate question prevention
- Follow-up questions
- Final interview score
- Performance progress report
- Fully responsive design
- Modern dark/red UI

## Technologies Used

- HTML
- CSS
- JavaScript
- AI API

## Interview Flow

1. Select an interview topic
2. Choose subtopics
3. Start the interview
4. Answer 10 questions
5. Difficulty adapts based on performance
6. Receive a final performance report

## Project Purpose

This project was developed as an internship training project to demonstrate an Adaptive Interview Engine that simulates how a real technical interviewer changes questions according to a candidate's performance.
