# AI Adaptive Interview Engine

An AI-powered interview system that dynamically adapts questions based on the candidate's performance.

## Features

* Adaptive difficulty based on answers
* Generates relevant follow-up questions
* Maintains interview context
* Tracks difficulty progression
* Handles skipped questions
* Detects repeated answers
* Prevents duplicate questions
* Generates a final performance report

## Technologies

HTML, CSS, JavaScript, AI/API

## Objective

To simulate a real technical interview where questions dynamically change according to the candidate's knowledge and performance.
